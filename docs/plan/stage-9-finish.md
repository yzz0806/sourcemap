# Stage 9 — Finish

## Goal
Someone else can run the demo from the README alone; docs match the code; open items are honest.

## What gets built
- README: install, keys, build, seed, one maintenance run, open the map, and a 5-minute demo
  script (map → cell → verdict → raw evidence; merged data and why each value won; history with the
  broken source and the departure).
- Docs reconciled with the code; component docs list the real functions.
- `docs/agent/log.md` with open items (e.g. "reports_to is mostly unverifiable until team-page and
  job-post adapters exist").

## How you check
1. Clone into a new folder; following only the README, install, build, seed, run one maintenance
   run and see the map in the browser.
2. Pick 3 functions named in the component docs: they exist and do what the docs say.
3. The log lists open items honestly.

## You need to provide
Someone (or you, in a fresh folder) to follow the README from scratch.

## Cost
About $1 (one test-mode maintenance run during the README check).

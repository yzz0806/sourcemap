THE MISSING LAYER

Web search ranks pages by popularity.
sourcemap routes a question to the sources measured to be right.

Ask an agent for Samsung Electronics' marketing org chart and web search returns news and company pages — about ten people, unverified. The full answer, 93 marketing executives with official titles, sits in Korea's DART filings, which search barely ranks. Between the agent and web search sits a library: for each data type and segment, which sources to cite, how accurate they are, and which search provider reaches them.

04 · METHOD

How the library is built and kept honest

HONEST LIMITS

  • Three companies per segment: intervals are wide; numbers describe these panels.
  • Outside Korea, official filings list only top officers, so most marketing claims are unverifiable — never counted as wrong.
  • Employment can only be confirmed with these references; title accuracy is the number that exposes errors.
  • Extraction and matching are model calls that must quote the page and the reference; the judge's own error rate is not measured against humans.
  • SAP has no reference: its site forbids automated reading. Sources that block reading are shown as blocked, never 0%.
